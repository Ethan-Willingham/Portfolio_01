# Archived post revisions

The owner selected these 18 posts for separate editorial reviews on October 3,
2026. Each post received a dedicated GPT-6.1 Sol agent at extra-high reasoning.
The work covers accuracy, useful length, natural prose and the opening layout
used by the sacred-book readings.

Each review records the reader's payoff, the original weaknesses, checked sources,
corrections, cuts, retained material and verification. Main reading paths and
optional reference material are assessed separately. Personal claims are preserved
only where the existing post supplies them. Interpretations and model outputs are
identified where readers encounter them.

The existing interactive tools, archive URLs, archive banners, images and credits
remain part of each post. A shared stylesheet, `archive/editorial.css`, supplies
the centered title, standfirst, metadata and responsive spacing. Its scale follows
the Quran, New Testament and Bhagavad Gita pages.

All eighteen revisions have passed their individual editorial and independent
reviews. Final publication checks cover both desktop and phone layouts, retained
tools and all twenty-three first-year charts.

The machine-readable queue is in `progress.json`. Each post has its own review
file in this directory. Completion requires both its editorial pass and a separate
review of the result, followed by desktop and phone browser checks.

[Independent reviews and browser results](VERIFICATION.md) record root's
acceptance of each post. The [separate integration audit](integration-audit.md)
records structure, retained assets, accessibility and no-JavaScript checks.
The first-year guide also has a [complete reference audit](the-first-year-reference.md)
and an [official programme comparison audit](the-first-year-countries.md).
