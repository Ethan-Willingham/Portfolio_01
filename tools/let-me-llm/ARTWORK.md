`source/the-love-letter.jpg`. The crop uses left 1000, top 1400, width 2550,

Run `node tools/let-me-llm/build-art-thumbnail.cjs` from the repository root.

sibling. The homepage metadata and generated card record the artist and source.

too plain beside the site's other pictures. The original UI thumbnail renderer
remains available for its existing OG artwork; the homepage uses the painting.
